PRIMERA ENTREGA - GRUPO 6 - AEROLINEA VIP (ASP.NET MVC, .NET Framework 4.8.1)

CONTENIDO DEL ZIP
  Script_BD_AerolineaVIP.sql   Script SQL (bases AerolineaVIP y AerolineaVIP_Identity). Se ejecuta primero.
  Prog_03.slnx                 Solucion de Visual Studio (apunta a ConAutenticacion\ConAutenticacion.csproj).
  ConAutenticacion\            Proyecto web. Excluye bin, obj, packages, .vs y archivos .mdf/.ldf.

ORDEN DE PRUEBA
  1. Ejecutar Script_BD_AerolineaVIP.sql en SQL Server (SQL Server 2019, localhost, usuario sa).
  2. Restaurar paquetes NuGet (packages.config) y compilar la solucion.
  3. Ejecutar la aplicacion. Al iniciar, Startup.cs crea los roles y los usuarios de prueba.

LIMITACIONES CONOCIDAS
  - El codigo no se compilo en el entorno de elaboracion. Debe compilarse y probarse en Visual Studio.
  - Los pagos son simulados. Una tarjeta cuyo numero termina en 0000 se rechaza.
  - La recuperacion de contrasena no envia correo: no hay servicio de correo configurado.
  - Pantallas 18 a 20: se usan los CRUD existentes (Vuelos, Aeronaves, Reservas) y una vista de lectura de usuarios.
  - Pantalla 21: consultas en pantalla; no hay exportacion.
